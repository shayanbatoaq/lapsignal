# Trademark and compatibility usage

LapSignal is an independent telemetry analysis prototype and is not affiliated with or endorsed by any game publisher, racing series, governing body, console manufacturer, or vehicle manufacturer.

Names such as F1 2021 and PlayStation are used only in plain text to describe technical compatibility and setup. The UI and repository must not use publisher/series/console logos, copyrighted game screenshots, official car liveries, team marks, or visual styling that implies sponsorship. Synthetic sessions use generic category descriptions and original visuals.

Do not write “official,” “partner,” or similar claims. Future adapters should follow the same nominative-compatibility approach and undergo legal review before commercial distribution. LapSignal's circuit-wave mark is original code-native artwork; trademark availability has not been cleared.
