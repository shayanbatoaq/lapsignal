# LapSignal Logo System

LapSignal's identity combines a racing-line `LS` monogram with a compact timing node. The mark is designed to feel like a serious sim-racing coaching product: precise, fast, technical, and distinct from racing-team or generic AI branding.

## Core palette

| Role | Name | Hex |
| --- | --- | --- |
| Primary background | Carbon Black | `#080A0D` |
| Secondary dark | Graphite | `#15191F` |
| Primary accent | Signal Red | `#F23849` |
| Primary light | Bone White | `#F4F1E8` |
| Timing accent | Warm Amber | `#F2B84B` |

Warm Amber is a timing-point accent only. It should never compete with Signal Red or become a large background colour.

## Recommended use

- Use the horizontal lockup in navigation bars, landing-page headers, presentations, and sponsorship-style placements.
- Use the standalone mark for the favicon, PWA icon, Windows collector, social avatar, loading state, and compact mobile navigation.
- Use the full-colour mark whenever the background provides sufficient contrast.
- Use a single-colour version for engraving, embroidery, stamps, or layouts where colour reproduction is unavailable.
- Maintain clear space of at least one logo stroke width around every side.
- Recommended minimum digital width: `120 px` for the horizontal logo and `24 px` for the standalone mark.

## Do not

- Stretch, rotate, outline, bevel, or add shadows/glows to the logo.
- change the relationship between the symbol and wordmark.
- replace Signal Red with a Ferrari-like scarlet or make Warm Amber dominant.
- place the full-colour mark on a low-contrast red, orange, or busy photographic area.
- add checkered flags, cars, steering wheels, publisher logos, or motorsport trademarks.

## Production note

These are high-resolution raster identity assets. Before large-format print, merchandise manufacturing, or a trademark filing, recreate and approve a true vector master with the wordmark converted to outlines. Keep the raster kit as the visual reference for that vectorization.
