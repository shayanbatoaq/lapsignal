# Roadmap

## Phase two: durable private beta

- Persist live sessions end-to-end instead of keeping live state primarily in the bounded in-memory buffer.
- Add authenticated accounts, tenant authorization, PostgreSQL, object storage, background analysis jobs, and data-retention controls.
- Complete signed collector enrollment, resumable artifact upload, encrypted retry queue, and richer compatibility negotiation.
- Expand traffic, fuel-corrected pace, tyre temperature/wear, energy, pit-cycle, and endurance phase analysis only where measured channels support it.
- Add production adapters for newer F1 titles, ACC, Le Mans Ultimate, and iRacing with independently verified fixtures and licensing records.
- Add durable cross-session profiles, confidence calibration, input-device migrations, and richer achievement rules based only on stored data.
- Gate real-model coach evaluations, trace redaction, token/cost accounting, and human-reviewed prompt releases.
- Explore a thin Tauri shell and native mobile companion after the HTTP/WebSocket contracts stabilize.

## Deliberately deferred

Payments, public leaderboards, social feeds, setup marketplaces, live AI voice coaching, publisher login integrations, and multiple competing agents remain outside the near-term plan. The product's priority is credible long-run evidence, not surface-area growth.
